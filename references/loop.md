# 收敛，与五个偏离的形状

循环怎么转、五问各是什么，见 [`core.md`](core.md)。这份文件只管一件事：**这棵树有没有在收敛**，以及它偏掉时长什么样。

## 收敛：节点可以无限长，未定项不能

**节点数不设上限**——一个问题答不完就再开一个节点，一条线走不通就换一条。但**收敛的判据是硬的：这个新节点有没有产生新的理念上的问题。**

```
未定项 = 这一步结束时仍然没确定的事（写进 ## 未定项，每条注明什么事实能解开）
```

| 情况 | 判词 |
|---|---|
| 把自己认领的未定项解决了，且没有长出新的 | 在收敛。`undecided` 归零，可以往下一步走 |
| 解决了一部分，长出了新的 | 正常。新的未定项决定下一个节点谈什么 |
| **连着几个节点，未定项只增不减** | **没在收敛，在铺摊子。** 停下来，明说这件事，别用漂亮话拖下去 |

**停的条件**：未定项全部被解决且不再增长，概念**自洽**（每个部分都能被同一套说法解释）且**可实现**（能指到具体机制或接口）。两样都到了，写进 `model.md`；还没到，写进「还没确定什么」，每条注明什么事实能解开。

**"未定项清零"的判据是写下来的：** 它是 `model.md` 里那一节真的空了，或者每一条都写着"什么事实能解开、而现在拿不到"。

## 五个偏离的形状

### 一、拆出来的词另有来源

**症状**：需求里明明写着"现代的、美观的"，推演链上四条线却换成了自造的名目（控制线、可读线、干预线、信任线），"美观"只在最后被抽象成一句"状态密度与注意力预算的匹配"。

**怎么发生的**：循环第一步写成了"拆成客观问题"，没写"拆的是需求自己的词"——于是模型自己发明了四条听起来更专业的线，用户的词被换掉了。

**防法**：拆词列成表，左边一列就是需求里的词；形容词必须拆到"怎么评价"为止。需求线里出现需求中没有的名目，就是拆错了。

### 二、一条需求线吃掉整棵树

**症状**：核心问题写成一句查账问题（"哪部分钱是白花的"），另一条需求线在全部推演节点里出现 0 次；11 个节点全在成本侧，效果侧等用户自己写出来。

**怎么发生的**：写种子之前先做了一轮成本调研，核心问题是在调研之后写的——轨道在这里就铺歪了，后面每一步都合规。

**防法**：种子先立（一句话需求、需求线、**核心与放弃代价**、检验条件、核心问题），再出去调研；核心问题必须同时压住每一条线，压不住就在种子里明写哪条降级、为什么。

### 三、最近调研到的东西当了推演的引子

**症状**：每个节点的 `from` 里躺着这一步刚测出来的那条事实，`from` 里的结论只是装饰；结论跟着测量跑，测量又生出下一个"要测一个数"的问题。12 个节点里好几个的问题本身就是测量题（命中率多少、模型会不会回去取），最后变成"用户说一条经验 → 我去量 → 报告我量到了什么"。

**怎么发生的**：纪律里写了"想谈现有系统就把它当外部事实去查"，于是"查"被当成了推演的内容。

**防法**：每一步的内容都由前面已经写下的东西得出——论证里查到的事实进 `facts.md` 与 `## 已知`，推演节点里写"这条事实让哪条结论变成什么"。**一个节点里得出的是概念或判断，"我量到 X"是一份材料。**

### 四、节点在长，未定项也在长

**症状**：节点数一路加，`## 未定项` 越写越长：一开始三条，第五个节点八条，第十二个节点十四条。每个节点单看都合规——有概念、有结论、有去向——但**没有一个环节被真正关掉**。讨论看着很深入，收不了尾。

**怎么发生的**：循环里写了"概念必须生出下一个问题"，却没写"未定项必须被解决"。于是长出新问题成了每个节点的成绩，解决问题反倒没人要求。**节点无限增长这条被当成许可用了。**

**防法**：每个节点收工前问一句——**这个节点认领的未定项，关掉了吗？长出了几个新的？** 数目只增不减就是没在收敛。要么把一个未定项真正解决掉（哪怕结论是"这条走不通"），要么明说这棵树没收敛、卡在哪一条上。

### 五、实验只是为了证明自己

**症状**：`build/03-实验.md` 写着"已验证可行"，点开看是一个能跑通的最小例子——它只演示了设想能工作，没有任何一种结果会让理念失败。或者反过来：实验跑了，结果被打圆，理念一个字没改。

**怎么发生的**：试运行被当成了证伪。循环里没写"跑之前先写杀判据"，于是实验自然长成了演示。

**防法**：**没写杀判据的不算实验，算演示。** 一个实验只回答一个问题，跑之前先写死"什么结果会杀死这个理念"。结果回来了就写"它让哪条结论变成什么"——**推翻了就写推翻**，一次成功的证伪比十个确认值钱。如果证据指向"这个需求做不到"，把它写成结论，那是这棵树最省钱的产出。
